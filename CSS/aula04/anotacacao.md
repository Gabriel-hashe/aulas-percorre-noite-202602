# Box model
O CSS enxerga os elementos d HTML como caixas que possuem algumas propriedades.

## Margin
Margem  é o espaço que distancia um elemento do outro, ou seja, é essa medida que faz un páragrafo ir para longe de uma imagem.

## Border
Para contornar um elemento  podemos configurar uma borda, a borda nada mais é do que  uma linha  em volta do elemento que fica entre a margin e o padding.
